# Базовые шаги Vanessa Automation (шпаргалка для наполнения фич)

> Синтаксис шагов VA зависит от версии фреймворка. Здесь — наиболее стабильные шаги.
> Верно: если шаг в фиче не распознан, VA отметит сценарий как ошибочный с пояснением —
> итерация быстрая. Проверять по своей версии: https://pr-mex.github.io/vanessa-automation/dev

## Контекст (начало каждой фичи)

```gherkin
	Контекст:
		Дано Я запускаю сценарий открытия TestClient или подключаю существующий
```

## Открытие объектов (smoke)

```gherkin
		Когда Я открываю навигационную ссылку "e1cib/list/Catalog.Товары"
		Когда Я открываю навигационную ссылку "e1cib/app/Report.Продажи"
		Когда Я открываю навигационную ссылку "e1cib/data/Catalog.Товары?ref=..."
```

- `e1cib/list/<Вид>.<Имя>` — форма списка (справочники, документы, планы обмена, планы
  счетов/видов характеристик, перечисления, задачи, бизнес-процессы).
- `e1cib/app/<Вид>.<Имя>` — основная форма (отчёты, обработки).

## Работа с формой

```gherkin
		И В активном окне я нажимаю кнопку "Сформировать"
		И В таблице "Список" я нажимаю кнопку "Обновить"
		Тогда Появилось окно с заголовком "..."
		И Я закрываю текущее окно
```

## Код встроенного языка (библиотека ВстроенныйЯзык)

```gherkin
		Когда Я выполняю код встроенного языка
		"""bsl
			// произвольный код; исключение = ошибка шага
			Если Метаданные.НайтиПоПолномуИмени("Catalog.X") = Неопределено Тогда
				ВызватьИсключение "Объект не найден";
			КонецЕсли;
		"""
		Тогда Проверка прошла успешно
```

## Пользовательские шаги (проверки доработок)

Шаг `Тогда Проверка доработки объекта "Catalog.X"` VA при загрузке каталога фич предложит
создать шаблон обработки шага (epf) — в его модуль вписывается код проверки. Имя шага
можно оставить постоянным для всех объектов: код берёт параметр (полное имя объекта) и
выполняет общую проверку, либо делаются отдельные шаги под конкретные доработки.

## Полезные механизмы

- Теги `@Имя` — отбор сценариев при запуске (в форме VA: фильтр по тегам).
- «Структура сценария + Примеры» — параметризация одной проверки на списке объектов.
- Подсценарии (`И Дано <подсценарий>`) — переиспользование последовательностей шагов.
- Отчёты Allure/JUnit и лог выполнения — настраиваются в форме VA / профиле запуска.
